StayOS PMS Main PMS Screen (Application Shell) API Gateway Documentation Document Type: API Gateway Module: Main PMS Screen / Shell Status: Draft v1.0 1. Conventions Base URL: https://api.stayos.io/v1 These endpoints belong to the Main PMS Shell's backend, not Configuration's — Configuration has its own API Gateway doc and its own base path. Standard 200/201/204/400/401/403/404/409 response codes, { data, error, meta } envelope, as established in Configuration's API Gateway doc. 2. Auth & Session Method Endpoint Description Auth POST /auth/login Authenticate and issue the main session JWT (user_id, client_id, role_id, role_type) Public POST /auth/logout Invalidate the current session Authenticated GET /auth/me Return the current user's identity, role, and property (client_id) Authenticated 3. Shell Navigation Method Endpoint Description Auth GET /modules List all 11 modules with is_built status and whether the current role can access each — drives the sidebar Authenticated 4. Configuration Access Check Since Configuration is an in-app route rather than a separate application, there is no hand-off endpoint. The only server-side requirement is that every Configuration API call is checked against the same role_module_access rule as any other module: Method Endpoint Description Auth * /configuration/** All Configuration endpoints (documented separately in Configuration's own API Gateway doc) reject with 403 if the caller's role lacks module_key = 'configuration' in role_module_access Authenticated
